# Memoflows

Personal timeline journal. One private log per user, browsed by date.

## Language

**Note**:
A body of text with zero or more photos, one timestamp, one owner.
_Avoid_: entry, memo, post

**Important**:
A note flagged by the owner, locked behind PIN.
_Avoid_: starred, favorite, pinned

**Rail**:
The vertical timeline for day, month, or year. Day rail shows 24 hour rows.
_Avoid_: list, feed, grid

**View**:
One of day, month, year, important. Set by breadcrumb, pager, or drill in.
_Avoid_: page, tab, mode

**Cursor**:
The focused date the current view renders around.
_Avoid_: selected date, active date

**PIN**:
Per user secret that locks important notes. Stored hashed in the DB, shared across platforms.
_Avoid_: password, passcode
